Neutral image-based lighting cubes derived from the Khronos glTF Sample Environments:
https://github.com/KhronosGroup/glTF-Sample-Environments/tree/main/neutral

Source: neutral/lambertian/diffuse.ktx2 and neutral/ggx/specular.ktx2.
The files are uncompressed linear RGBA16F DDS cubes. Diffuse was averaged to
64 pixels per face; specular levels 0-10 are spatially reduced and selected
across the full smooth-to-rough range (256 pixels down to 1).
No tone mapping or color conversion was applied.
